# Money Counter

An installable web app for counting cash. Tap the notes and coins in front of you and it keeps a running total, so counting a till or a drawer takes seconds instead of minutes.

**Live app:** https://omarfaruque1.github.io/money-counter/

## Features

- Tap-to-count notes and coins, with the running total pinned on screen
- Installable: "Add to Home Screen" opens it full screen, with no browser bars
- Works offline once it has loaded
- Light and dark themes, and it remembers which one you picked
- Mobile-first layout that also works on desktop

## Install it on your phone

1. Open the live app in your phone's browser
2. **iOS (Safari):** Share, then "Add to Home Screen"
3. **Android (Chrome):** menu, then "Add to Home screen"

## Built with

JavaScript, HTML and CSS, packaged as a progressive web app with a web app manifest and deployed on GitHub Pages.
